# Personal Portfolio with Flask

This is a simple personal portfolio website built with **Flask** and based on the **Identity template by HTML5 UP**.

The original template was downloaded from HTML5 UP and then customized with my personal information, profile image, social links, and Flask integration.

## Features

- Flask web application
- HTML/CSS personal portfolio page
- Custom profile image
- Personal developer information
- Social media links
- Responsive design
- Template rendered using Flask `render_template()`

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
